## 2024-05-24 - Animation Memory Leaks & O(n) List Rendering
**Learning:** `Animated.loop` in React Native creates a memory leak and continues running in the background if the reference is not explicitly captured and `.stop()` is not called in the `useEffect` cleanup function when dependencies change or the component unmounts. Furthermore, rendering a list where each item receives an un-memoized callback prop (like an inline function or an un-memoized function from the parent) causes O(n) re-renders for every single item in the list whenever the parent state changes (e.g., when one item is toggled).
**Action:** Always capture the `Animated.loop` return value and call `.stop()` in the cleanup function of `useEffect`. Use `React.memo` to wrap list items and pass stable callback props using `useCallback` (along with functional state updates like `setItems(prev => ...)`) to ensure only the updated list item re-renders, reducing rendering work from O(n) to O(1).
